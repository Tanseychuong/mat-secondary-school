# Mat Secondary School Website

A simple school website developed using:

- HTML
- CSS
- JavaScript
- jQuery
- PHP
- MySQL

## Pages

- Home
- About
- Academics
- News & Events
- Contact
- Admin

## Database

The application uses MySQL to store:

- News and events
- Contact enquiries

## Deployment

The application can be deployed using a free PHP/MySQL hosting provider such as InfinityFree.
